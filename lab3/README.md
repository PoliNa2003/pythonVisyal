# Лабораторная работа 3 — линии электрического поля

В `lab3.py` реализовано построение линий электрического поля системы из трёх точечных зарядов (вариант 2). Поле рассчитывается по принципу суперпозиции, линии интегрируются по нормированному вектору напряжённости. Все заряды положительные: `q₁=q₂=q₃=+1`; координаты: `(2, 0, 0)`, `(0, 2, 0)`, `(0, −2, 0)`. Заряды показаны красным.

## Выполненные пункты

Скрипт создаёт пять изображений, соответствующих базовым этапам методички: линии поля, стрелки направления, отображение глубины с затемнением дальних сегментов, ортографический вид и центральная проекция. Порядок сегментов по глубине используется для наглядной имитации удаления скрытых частей; полноценный пиксельный Z-буфер относится к возможностям исходных C++ проектов.

## Запуск

Из каталога `lab3`:

```powershell
python lab3.py
```

Нужны Python, NumPy и Matplotlib. При запуске все пять графиков сохраняются в `lab3/results/` и открываются в окнах Matplotlib. Закройте окна графиков, чтобы завершить программу.

Файлы `electric_field_02.png`–`electric_field_06.png` соответствуют последовательным вариантам визуализации из задания.
