# Лабораторная работа 2 — металлические волноводы

Реализация варианта 2 для моды H₁₁ (TE₁₁) находится в `lab2.py`. Скрипт рассчитывает физические параметры прямоугольного и круглого металлических волноводов, выводит их в консоль и сохраняет восемь графиков в каталоге `results`. В каждом сечении выполнены задания на дисперсию, картину полей, поля вдоль контура и поверхностные заряд и ток.

## Параметры варианта

- Мощность переносимой моды: 800 Вт.
- Прямоугольный волновод: `a = 3 см`, `b = 1 см`, мода H₁₁.
- Круглый волновод: радиус `a = 3 см`, мода H₁₁. Использован первый ненулевой корень уравнения `J′₁(μ) = 0`, `μ ≈ 1,84118378`.
- Для расчёта амплитуд поля рабочая частота выбрана равной `1,5 fс`, как в MATLAB-примерах. На линиях поля используется момент времени `t = T/8`.

## Запуск

Из каталога `lab2` выполните:

```powershell
python lab2.py
```

Нужны Python, NumPy и Matplotlib. Дополнительный пакет SciPy не требуется. При запуске для обоих сечений выводятся частота отсечки, рабочая частота, постоянная распространения, длина волны в волноводе, фазовая и групповая скорости, амплитуда моды, максимумы `E`, `Bτ`, `Bz`, `Hτ`, `Hz`, поверхностной плотности заряда и поверхностных токов.

## Результаты

Графики разделены по типу волновода. Номера файлов соответствуют пунктам задания; задание 1 и 6 — расчёт физических параметров, поэтому отдельного графика для них нет. Для прямоугольного сечения контур обходится из точки `(0, 0)` против часовой стрелки, как указано в `Variants_r.doc`.

### Задания 1–5 — прямоугольное сечение

Каталог `results/01_rectangular`:

- `03_field_lines.png` — эквипотенциальные линии и векторы поля в сечении.
- `04_fields_on_contour.png` — распределение `E`, `Bτ` и `Bz` по периметру.
- `05_charge_current.png` — поверхностная плотность заряда и компоненты поверхностного тока по периметру.

### Задания 6–10 — круглое сечение

Каталог `results/02_circular` содержит те же четыре типа графиков для круглого волновода; на графике дисперсии показана H₁₁ и пунктирная зелёная линия `β = 2πf/c`. На графике 03 линии потенциала синие, красные векторы увеличены. На графиках 04–05 `Bz` и `jsτ` красные, `Bτ` и `jsz` зелёные.

Магнитные поля на графиках контурного распределения приведены в микротеслах, остальные единицы указаны в подписях и легендах. Прямоугольный контур отсчитывается последовательно по четырём стенкам; круглый — по длине окружности от `s = 0` до `s = 2πa`.

Для графика 03 прямоугольного сечения использованы раздельные сетки для контуров и векторов, как в `E_type.m`. Формула потенциала взята из `H_type.m`, поскольку `E_type.m` описывает TM-моду, а вариант задан для TE-моды H₁₁. Контуры показаны синим, векторы — красным.

На графике 04 знаки компонентов сохранены по формулам `Contour_TE_r.m`: для H₁₁ компоненты `E` и `Bτ` отрицательны на правой и левой стенках из-за коэффициентов `(-1)^n` и явного минуса в формулах этих стенок. Это знаковое распределение; замена значений на модуль исказила бы заряд на графике 05. Цвета графика 04: `E` — синий, `Bτ` — зелёный, `Bz` — красный. На графике 05 цвет `ρs` — синий, `jsz` — зелёный, `jsτ` — красный; знак тока `jsτ` противоположен знаку `Bz` по формуле `jsτ = −Bz/(μ₀·100)`.
